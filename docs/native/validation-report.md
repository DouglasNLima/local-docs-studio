All four large-block viewport PNGs were inspected with their final text visible. The diagnostic viewer measures both initial attachment and explicit 640 × 300 layout; it does not establish a universal application frame time. A 128-item list-group experiment showed no useful improvement and was removed. The retained trace is layout-profile.nettrace. Final layout, very large individual paragraphs/code blocks, incremental reuse and broad high-DPI/scrolling remain incomplete measurements.

The first long-editor timing attempt exposed an offscreen target: after ScrollToLine and layout, the final source position was at Y=668.5 in a 480-pixel viewport. Those initial edit timings are not treated as visible editing evidence. The corrected shared navigation waits for actual wrapped-line layout and verifies positions; Find, source/outline, review and map navigation use it. Source/selection/document changes and newer requests cancel stale work. Focused and full native checks pass; desktop workflow 55 awaits CI. Warm-process memory samples are retained without forced collection; they include the validation host and earlier checks and do not establish an application leak. Actual application startup, keyboard, save and image-paste observations now record process memory alongside elapsed workflow time; their CI evidence remains pending and includes UIA/100 ms polling overhead.
