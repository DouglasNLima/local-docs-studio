# Native experience improvements

Word lists supplied by paragraph styles now retain their markers, hierarchy and continuation placement. Default/inherited styles, explicit overrides and linked numbering definitions have 14 new core cases; all 912 tests and the full native harness pass locally. Twelve actual DOCX items converted to inherited styles return exactly the same Markdown. The separate CRLF block assertion failure is reproduced and corrected; CI still needs to validate this batch, and the recurring details-construction delay remains unresolved.

Word code paragraphs now return as literal fenced code, and consecutive quote paragraphs remain one quote, including supported list placement. Fourteen new cases pass within 897 core tests; native export/reimport verifies exact code and quote boundaries. Style inheritance is bounded, generic spacing styles are not guessed to be code, and table/image fallbacks carry explicit notes. Code language and deeper quote structure remain outside the reconstructed semantics; this later change still needs its own CI.

Imported Word links retain supported web/email destinations and referenced internal bookmarks. Formatting and linked image bytes are covered by 15 new regressions, with all 883 core tests and the complete native harness passing in both 0d9d54f hosted runs. Unsupported targets and inert field results have explicit warnings; no document-provided link is fetched during import.

Word import now keeps direct list starts, hierarchy and continuation paragraphs, and corrects heading-level demotion. The 868-test core suite and complete native harness pass in both 4cbce1d hosted runs; six prepared lists and both native image payloads survive reimport. Unsupported markers and flattened table-cell lists have explicit warnings. Full destination formatting remains incomplete; evidence is in the [validation report](validation-report.md).

The native edition improves local document workflows through Windows controls, filesystem ownership and portable files. The outcomes below are implemented with the stated limits; they do not establish production certification. The [parity matrix](functional-parity-matrix.md) and [validation report](validation-report.md) carry the contracts and evidence.

Current verified preview.240 passes actual installation, upgrade/reinstall, restored sessions and 62 desktop checks in four contexts. Installed applications load their bundled .NET/WPF runtime. Both native and both web runs pass at 0d9d54f on their first attempts, including Word export, list/heading reimport and supported hyperlinks. User-controlled updates retain empty production trust and block unsigned execution. SDK-free Windows, physical accessibility/display tests and a production signing identity remain outstanding.

Recent export corrections keep list items intact: PDF uses one marker and distinct indentation across nested/continued paragraphs; Word uses native editable numbering and explicitly suppresses inherited numbering on continuation paragraphs. Image/table widths respect the remaining space. The PDF change passes both native CI runs, with byte/geometry checks and seven inspected hosted pages. The later Word change has eleven new core regressions and native Mermaid/formula package checks, with all 850 core tests and the complete native harness passing locally. Actual Word destination layout remains unverified.
