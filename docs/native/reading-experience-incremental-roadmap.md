Recommended sequence: finish the statistics provenance/review decision, then
Outline/Copy TOC (high utility, read-only and independent), slash commands
(authoring value with a contained editor boundary), then comparison (largest
ownership and Save/recovery surface). Flowchart and main-reader reflow need no
recovery PR. Each future slice needs its own current-develop baseline, focused
source-preservation/accessibility validation and provenance decision.

PR #76 stays Draft and unmerged; Goal #75 remains open. PR #78 is unchanged.
No additional feature PRs, performance campaigns or acceptance-policy changes
are part of this roadmap. Public release and Native Stable remain NO-GO.
