## Execution boundary

The existing registered workflow gains an isolated `bounded_protocol=R01` dispatch.
All original observer, contract, calibration and discovery jobs are excluded from
that mode. The wrapper requires an exact coordinator commit, the owner actor,
the feature branch, a GitHub-hosted Windows runner, and run attempt 1. It verifies
the authorisation's exact comment body, run identity and artefact ZIP hash before
restoring all 2,019 files. GitHub API credentials exist only in that download step.

The coordinator is copied outside the checkout, then the checkout is detached to
the exact reviewed implementation. No native source or binary is rebuilt or changed.
Before loading any input/appearance API, the original validator checks the clean
tooling checkout, source receipt, fixture and generated sources, all three complete
binary bundles, both runtime closures, SDK files, full Windows build/UBR and exact
image version. Any drift blocks execution; neither a newer image nor a different
runtime can be substituted. The original candidate configuration remains byte-for-byte
unchanged. A separate execution copy changes only its status, approval Boolean and
owner-authorisation URL.

R01 uses its original four cells, seven boundaries, three fixed frames per boundary,
84-frame/252-crop maxima, Pages/100% zoom, 30-second observation deadline and
240-second child supervision. Existing ownership, selection, geometry, UIA and
pixel assertions remain intact. Trace-off does not acquire trace hooks. Windows
appearance, held input and each child job's empty process tree must be verified
after collection. A child assertion failure retains a non-zero workflow result;
collection safety cannot convert it to PASS. Every partial output is uploaded.

R02 is deliberately absent from the initial dispatcher. Independent review of
the actual R01 artefact, full frames, original audit and restoration evidence must
produce an exact, source-bound technical disposition before exposing its 18-process
stage. A valid product failure can coexist with permission to investigate R02;
missing safety evidence, environment drift or invalid shared infrastructure cannot.
No workflow rerun, replacement cell, image substitution or calibration is permitted.
