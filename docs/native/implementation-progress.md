- Serial background raster preparation with frozen image reuse by content hash and aggregate/cache budgets. Native layout performs no image file reads. FlowDocument construction now yields in cancellable dispatcher batches while retaining the old preview until a complete current result is ready; pagination and incremental reuse remain open.
- Bounded ZIP, DOCX, HTML and PDF text imports; guarded DOCX, HTML, local PDF and generic Markdown Bundle exports. Template styles and package headers/footers/media are preserved, with full template contracts still incomplete.
- Markdown Bundle export excludes the configured private state folder and rejects a workspace inside it. - Native Docs Site options and guarded ZIP output retain current saved-file drafts, bounded front-matter metadata, embedded native images/diagrams, rewritten document links, generated/readme home, search and light/dark/system themes. Private native state is excluded; generated scripts run only in the exported site.
- Docs Site section search retains nested headings, code/table text, distinct metadata and unique heading targets. Search indexing checks entry/byte budgets before serialisation; client searches yield and cancel obsolete results.
- Copy rendered content prepares sanitised CF_HTML and Unicode text, embedding native images/diagrams and retaining table cells. Source/image limits, cancellation and clipboard sequence checks protect preparation; external destination fidelity remains to be validated.
- Automatic HTML/TSV paste and nine Paste Special modes, including literal text with Ctrl+Shift+V. HTML import shares conversion for nested lists, code delimiters, literal punctuation and bounded merged tables. Embedded images are persisted before an undoable anchored source replacement.
- Copy Markdown with images retains literal source around prepared images/complete Mermaid blocks and carries ordered image elements in CF_HTML. Native paste saves embedded raster data to portable assets. Remote references and incomplete fences stay literal; shared image references expand only at their image occurrences.
- Native callouts retain labels, formatted content and source mapping. Ordered starts, including zero, table alignment, independent emphasis, scripts, insertion/highlight and soft/hard line breaks render correctly. DOCX preserves these text properties; PDF preserves supported properties and explicit deletion markers.
- Bounded passive status/keyboard snippets retain decoded selectable text and source mapping in WPF and document exports. Imported attributes do not reach controls. Unsupported content retains its original tree; literal source copy remains unchanged. HTML entities are preserved in headings, preview and exports.
- Passive progress snippets become labelled native WPF progress controls with accessible range values. A native insert/edit dialogue validates label/percentage/colour and applies one source replacement with preserved selection, scrolling and Undo/Redo. DOCX/PDF retain labelled coloured bars; HTML and Docs Site retain semantic progress elements. Unknown structures remain visible as source.
- Named/empty document anchors share unique source-aware targets with headings. Native preview and the link picker resolve those targets; the picker uses current tab buffers. An insert/edit dialogue keeps existing identifiers and applies labels as one undoable action. HTML/Docs Site preserve identifiers, while Word/PDF create local bookmarks and links without importing active attributes.
- Editor context actions target the native editor for Undo/Redo, Cut/Copy/Paste and selection, plus existing formatting/link commands. Preview code context actions copy bounded Unicode code or original Markdown with fences, line endings and nested quote context; menus stay outside document/export text.
- Fenced-code preview uses bounded background syntax preparation from fourteen bundled language families. Fixed light/dark colours preserve selectable Unicode/CRLF text and source mapping; high contrast inherits system colours. Unknown/oversized/timed-out blocks retain full plain text. Source and exports are unchanged.
- Editor Markdown highlighting uses readable theme palettes before native selection styling. Lens accent selection retains dark text; high contrast uses system text/highlight colours. Bounded scans fall back to inherited text, and theme changes redraw current lines without replacing source or selection.
- Core source-edit plans and a separate AvalonEdit formatting service provide toggled/nested emphasis, line-based headings/lists/quotes, adaptive code fences, retained template selection and five callout insertions. Each plan is one undo group; selected placeholders support immediate typing without replacing structural markers.
- Native Mermaid completion offers thirteen existing snippets through typing, Ctrl+Space and the Edit menu. Context respects standalone documents and standard/Azure DevOps fences; accepted tokens preserve indentation/line endings and form one Undo action. Scans are bounded; wikilink completion remains separate.
- Fluent light/dark/system controls, high-contrast resources, working-area sizing and saved window placement. Operation and preview status are separate so preview completion cannot hide recovery feedback.
- Separate self-contained installer/portable packaging and native CI. Development-host preview 4 → 5 upgrade, uninstall/reinstall and preservation checks passed. Fresh Windows runners also exercise installed-app workflows.
- Compatible GitHub release discovery, channel preferences, signed-manifest policy, bounded downloads, integrity and pinned Authenticode checks, separate download/install consent and temporary update launcher. Production trust is unconfigured; unsigned builds cannot execute downloaded installers.
