## Implementation and interaction contract

- Web `refreshEditorFind` updates data, active-selection association, counter and overlay only. Query-focused refresh and explicit navigation alone select a match. Selection/click/key events update the active indicator without changing selection. Enter belongs to the query handler; the global handler retains Escape and scoped F3/Shift+F3 and ignores composition. Find & Replace and preview search keep their separate services.
- Native `RefreshFindAsync` only publishes current immutable-snapshot results. A named request records query/source/document/preview/navigation/replacement cause, generation and editor-interaction revision. Only a still-current focused query, explicit navigation or explicit replacement can reveal a result. Editor focus, key, pointer and wheel input cancel pending reveals; source invalidation cancels computations and navigation. The duplicate model invalidation is removed; binding an active document still invalidates independently. Replacement anchors are local to their authorised request. Existing navigation-service version/selection checks remain in force.
- Ordinary editing preserves the editor's caret, selection, focus, source and natural viewport; no old caret is restored. A counter displays an active index only for an exact selected source occurrence. Otherwise it displays `0/total` (Web) or `0 of total` (Native). Match limits, incomplete-search warnings and the native debounce remain unchanged. Existing preview mapping, formula handling and diagram-label exclusions are untouched.
- The service-worker cache revision changes to v73 so installed PWA shells acquire the correction.
