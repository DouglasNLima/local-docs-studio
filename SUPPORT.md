# Support

Lens Docs Studio is intended to remain free and community maintained, with no
subscriptions, paid licences or plan-based feature restrictions. Community
support has no guaranteed response time or commercial service level.
**@DouglasNLima** is the sole human community/support maintainer and may be
unavailable. There is no separate support team or independent project escalation.

For usage, start with the [web guide](docs/tool-guide.md) or
[native guide](docs/native/user-guide.md). Check [Windows readiness](docs/native/current-windows-readiness.md)
before installing a preview. Existing public Windows releases use the legacy
shell; they are not native Stable builds.

Use [GitHub issues](https://github.com/DouglasNLima/local-docs-studio/issues) for a
reproducible bug or feature request. Include the edition, version, operating
system/browser, expected result and a minimal synthetic example. Remove local
paths, customer data, tokens and personal information from logs or screenshots.
Do not upload an entire workspace by default.

Use [SECURITY.md](SECURITY.md) for vulnerabilities and
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct concerns. Licence adoption and
signed Stable distribution are still under review; see the
[readiness receipt](docs/open-source/README.md).
